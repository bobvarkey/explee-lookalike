# Leadwren — marketing site lookalike

Vite + React + TypeScript + Tailwind + lucide-react. Layout/interaction study of a modern AI-outbound landing page, with **original placeholder branding and copy**.

Rename the product: edit `src/config.ts` (`BRAND.name`). Also update `<title>` in `index.html`.

```bash
npm install
npm run dev     # local
npm run build   # static output in dist/
```

Deploy: import the repo into Vercel or Netlify (framework: Vite, build `npm run build`, output `dist`). Lovable can also import a GitHub repo.
